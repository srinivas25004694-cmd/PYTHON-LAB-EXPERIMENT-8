## Program 8 – Date Validation Using Regular Expression

### Aim
To validate a date format using the regular expression module in Python.

### Algorithm
1. Start the program.
2. Import the `re` module.
3. Get the date as input from the user.
4. Define a regular expression pattern to check the date format.
5. Use `re.fullmatch()` to check whether the input matches the pattern.
6. If the pattern matches, display "valid date format".
7. Otherwise, display "invalid format".
8. Stop the program.

## Program 8.1 – Email and Phone Number Validation

### Aim
To validate an email address or phone number using the regular expression module in Python.

### Algorithm
1. Start the program.
2. Import the `re` module.
3. Get the email address or phone number from the user.
4. Define regular expression patterns for email and mobile number.
5. Use `re.fullmatch()` to check the input against the email pattern.
6. If the input matches the email pattern, display "valid email".
7. Otherwise, check the input against the mobile number pattern.
8. If the input matches the mobile number pattern, display the valid message.
9. If neither pattern matches, display "invalid email or phone number".
10. Stop the program.
